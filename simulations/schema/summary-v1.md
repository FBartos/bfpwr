# Summary Schema v1

Analysis summaries contain Monte Carlo estimates and deterministic references
where available.

Required columns:

- `analysis_case_id`
- `design_case_id`
- `test_family`
- `bf_type`
- `nsim`
- `look_grid_name`
- `k1`
- `k0`
- `pH1`
- `pH0`
- `pInc`
- `EN`
- `VarN`
- `mcse_pH1`
- `mcse_pH0`
- `mcse_pInc`
- `reference_pH1`
- `reference_pH0`
- `reference_pInc`
- `reference_EN`
- `reference_VarN`
- `status`
- `notes`
