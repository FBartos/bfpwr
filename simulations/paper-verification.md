# Paper Verification Audit

Date: 2026-05-27

This audit checks fixed-sample calculations from `paper/bfssd.Rnw` and selected
sequential calculations from the external `SamCH93/bfgsd` paper source. The
external reference was fetched from `https://github.com/SamCH93/bfgsd` at commit
`fc9d9a0e5ec1922c014ec4e8220f72924541ea53`.

The result table is generated by:

```sh
Rscript simulations/scripts/verify_paper_values.R
```

`rpact` is not installed locally (`requireNamespace("rpact") == FALSE`), so the
classical O'Brien-Fleming boundary calls commented in the external paper source
were not rerun. The Bayes-factor calculations themselves do not require
`rpact`.

## Senior Assessment

The verification layer is stronger after this pass, but it should not be
described as a complete adversarial proof of every manuscript calculation.

What is strict/adversarial:

- Fixed-sample tinytests compare package functions against test-local
  closed-form calculations, direct numerical integration, exact enumeration, and
  wrapper/root checks.
- Sequential tinytests compare package outputs against manually constructed
  multivariate-normal stopping regions, including a three-look normal-prior
  case whose BF thresholds are found by independent root finding rather than by
  package `zcrit()` algebra.
- Sequential tinytests now cover the Low-PV three-look design, negative
  point-normal orientation, `VarN`, and a bounded check that the default
  `lpmvnorm` integration path remains close to the exact `pmvnorm` reference.
- Fixture-corpus tests and validators remain gated, deterministic, and
  reproducible without affecting CRAN-style checks.

What is not fully strict:

- `verify_paper_values.R` is a pinned-value/reporting harness. It does not purl
  or evaluate named chunks from `bfssd.Rnw` or `BFGSD.Rnw`, so source drift in
  the manuscripts is not automatically detected.
- Some fixed-formula references intentionally repeat compact algebra from the
  paper/package family. They catch regressions, sign changes, and wrapper
  breakage, but they are not independent derivations of every constant.
- The external JZS sequential appendix row is pinned against current deterministic
  output; the stronger adversarial MVN layer is in
  `test-paper-sequential-regions.R`.

Bottom line: no disagreements were found in the checked rows, and the highest
risk sequential region calculations are now tested adversarially. This is a
strong regression/verification layer, not a formal source-extraction proof of
the full papers.

## Test Coverage Added

- `package/inst/tinytest/test-bf01.R` now checks `log(res)` against `logres`
  instead of comparing `log(res)` to itself.
- `package/inst/tinytest/test-paper-fixed-formulas.R` adds deterministic
  checks for fixed-sample formulas, fixed-n wrappers, sample-size wrappers, and
  the mirtazapine manuscript BF/sample-size example.
- `package/inst/tinytest/test-paper-sequential-regions.R` adds manual
  multivariate-normal region checks for representative point-normal,
  directional, normal-moment, normal-prior, recentered nonzero-null, negative
  orientation, Low-PV, and one-sided t sequential designs.
- Existing fixture-corpus tests remain gated by `BFPWR_SIM_CORPUS` and
  `BFPWR_SIM_REPO`; ordinary CRAN-style tinytests do not require the corpus.
